# ExpanseTracker 

ExpanseTracker is a simple and user-friendly expense tracking application that helps users record, manage, and analyze their daily expenses. The goal of this project is to provide an easy way to keep track of spending habits and gain better control over personal finances.

---

##  Features

* Add daily expenses with amount, category, and description
* View all recorded expenses in one place
* Track total spending
* Simple and clean user interface
* Beginner-friendly project structure

## Installation & Setup

1. Clone the repository

   ```bash
   git clone https://github.com/dhavamani16/ExpanseTracker.git
   ```

2. Navigate to the project folder

   ```bash
   cd ExpanseTracker
   ```

3. Open `index.html` in your browser

   ```
   Right-click → Open with browser
   ```
